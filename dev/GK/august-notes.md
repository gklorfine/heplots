## Note re: RB

The following from [`GK-Project.md`](./GK-Project.md) is not strictly an RB test:

```
# Source - https://stackoverflow.com/q/79594493
# Posted by user101089
# Retrieved 2026-08-21, License - CC BY-SA 4.0

lm(cbind(y1, y2, y3) ~ x1 + x2 + x3 + ...)
lm(cbind(    y2, y3) ~ x1 + x2 + x3 + y1 + ...)
lm(cbind(        y3) ~ x1 + x2 + x3 + y1, y2 + ...)
```

RB tests are all univariate, so the following would be the RB version of the above idea:

```
lm(cbind(y1, y2, y3) ~ x1 + x2 + x3 + ...) # The 'overall' MANOVA

lm(y1 ~ x1 + x2 + x3 + ...)
lm(y2 ~ x1 + x2 + x3 + y1 + ...)
lm(y3 ~ x1 + x2 + x3 + y1 + y2 + ...)
```
